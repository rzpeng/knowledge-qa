### application.yml 配置
```yaml
server:
  port: 8081

spring:
  application:
    name: knowledge-feishu

feishu:
  enabled: false                    # 启用飞书集成
  app-id: your_app_id             # 飞书应用ID
  app-secret: your_app_secret     # 飞书应用密钥
  bot-token: your_bot_token       # 机器人访问令牌
  webhook-url: https://open.feishu.cn/open-apis/bot/v2/hook/your_webhook_hook
```

## 启动步骤

### 1. 环境要求
- Java 17+
- Gradle 8.0+
- 飞书开放平台账号

### 2. 配置飞书应用
1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 创建应用并获取 App ID 和 App Secret
3. 配置机器人权限
4. 获取 Bot Token 和 Webhook URL

### 3. 配置应用
编辑 `src/main/resources/application.yml`:
```yaml
feishu:
  enabled: true
  app-id: your_actual_app_id
  app-secret: your_actual_app_secret
  bot-token: your_actual_bot_token
  webhook-url: your_actual_webhook_url
```

### 4. 启动服务
```bash
# 使用Gradle启动
gradle bootRun

# 或者构建后运行
gradle build
java -jar build/libs/knowledge-feishu-1.0.0-SNAPSHOT.jar
```

### 5. 验证服务
访问 `http://localhost:8081/api/feishu/health`

## 集成说明

### 与现有系统集成
飞书模块可以独立运行，也可以集成到现有的知识库问答系统中：

```java
// 在现有服务中注入飞书服务
@Autowired

// 推送知识库问答结果
feishuService.sendKnowledgeAnswer(chatId, question, answer);
```
