# 飞书机器人配置指南

## 📋 参数获取步骤

### 🔑 Bot Token 获取

#### 步骤1：登录飞书开放平台
1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 使用飞书账号登录

#### 步骤2：创建应用
1. 点击"创建应用"
2. 选择"机器人"应用类型
3. 填写应用名称、描述等信息
4. 点击"创建"

#### 步骤3：获取应用凭证
在应用详情页面的"凭证与基础信息"中可以找到：
- **App ID**: 应用的唯一标识
- **App Secret**: 应用的密钥

#### 步骤4：获取 Bot Token
1. 在应用管理页面，点击"机器人"
2. 在"机器人信息"中，找到"访问凭证"部分
3. **Bot Token** 就在这里显示
4. 点击"复制"按钮获取 Bot Token

**Bot Token 格式示例：**
```
cli_xxxxxxxxxxxxxxxxxxxxxx
```

### 🔗 Webhook URL 获取

#### 步骤1：配置机器人权限
1. 在应用管理页面，点击"机器人"
2. 在"权限管理"中，确保已开启以下权限：
   - `im:message` - 发送消息权限
   - `im:message:send` - 发送消息权限
   - `im:chat` - 群聊权限

#### 步骤2：配置事件订阅
1. 点击"事件订阅"
2. 开启"事件订阅"功能
3. 添加以下事件类型：
   - `im.message.receive_v1` - 接收消息事件
   - `im.chat.member.added_v1` - 群成员添加事件
   - `im.chat.member.removed_v1` - 群成员移除事件

#### 步骤3：获取 Webhook URL
1. 在"事件订阅"页面，找到"请求验证URL"部分
2. **Webhook URL** 就是这里配置的地址
3. 格式如下：
   ```
   https://open.feishu.cn/open-apis/bot/v2/hook/your_webhook_hook
   ```

#### 步骤4：配置安全设置
1. 在"安全设置"中，配置IP白名单
2. 添加您的服务器IP地址（例如：127.0.0.1 或您的公网IP）
3. 设置请求验证Token（可选）

## ⚙️ 配置文件示例

### application.yml 配置

```yaml
server:
  port: 8081

spring:
  application:
    name: knowledge-feishu

# 飞书配置
feishu:
  enabled: true                    # 启用飞书集成，true=启用，false=禁用
  app-id: cli_xxxxxxxxxxxxxxxxxx  # 替换为您的飞书应用ID
  app-secret: xxxxxxxxxxxxxxxxxxxx # 替换为您的飞书应用密钥
  bot-token: cli_xxxxxxxxxxxxxxxxxx # 替换为您的机器人访问令牌
  webhook-url: https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxxxxxxxxxx # 替换为您的Webhook URL

# 日志配置
logging:
  level:
    com.knowledge.feishu: DEBUG
    org.springframework.web: DEBUG
```

### 环境变量配置（推荐）

创建 `.env` 文件：
```bash
FEISHU_ENABLED=true
FEISHU_APP_ID=cli_xxxxxxxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxx
FEISHU_BOT_TOKEN=cli_xxxxxxxxxxxxxxxxxx
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxxxxxxxxxx
```

## 🚀 启动步骤

### 1. 环境准备
```bash
# 确保Java 17+已安装
java -version

# 确保Gradle 8.0+已安装
gradle -version
```

### 2. 配置飞书参数
编辑 `src/main/resources/application.yml`，将以下参数替换为您的实际值：
- `app-id`: 您的飞书应用ID
- `app-secret`: 您的飞书应用密钥
- `bot-token`: 您的机器人访问令牌
- `webhook-url`: 您的Webhook URL

### 3. 启动服务
```bash
cd knowledge-feishu
gradle bootRun
```

### 4. 验证服务
```bash
# 检查服务状态
curl http://localhost:8081/api/feishu/health

# 测试发送文本消息
curl -X POST "http://localhost:8081/api/feishu/message/text?chat_id=test&text=Hello"
```

## ⚠️ 注意事项

### 1. 权限配置
- 确保飞书应用已开启必要的权限
- 检查事件订阅是否正确配置
- 验证IP白名单设置

### 2. 网络配置
- 确保服务器可以访问飞书API
- 检查防火墙设置
- 验证端口8081是否开放

### 3. 安全建议
- 不要在代码中硬编码敏感信息
- 使用环境变量或配置文件管理敏感数据
- 定期更新飞书应用的访问令牌

### 4. 错误处理
- 检查飞书开放平台的错误日志
- 验证请求格式是否正确
- 确认消息内容是否符合飞书规范

## 📞 故障排除

### 常见问题

#### 1. Bot Token 无效
- 检查Bot Token是否正确复制
- 确认应用状态是否正常
- 验证访问令牌是否过期

#### 2. Webhook URL 无法访问
- 检查URL格式是否正确
- 确认服务器IP是否在白名单中
- 验证网络连接是否正常

#### 3. 消息发送失败
- 检查机器人权限是否正确配置
- 确认消息格式是否符合要求
- 验证聊天ID是否正确

### 调试建议
1. 启用DEBUG日志级别
2. 使用curl命令测试API接口
3. 检查飞书开放平台的开发者工具
4. 验证请求和响应的详细信息
